Create, edit, duplicate, import and export profiles. Keep mods, configs, saves and logs in isolated directories.

Keep your servers close

Built in the open.
Still taking shape.

Astrix continues the existing Flash Client prototype, built with Electron, React, TypeScript and Vite.

Microsoft sign-in, Minecraft ownership checks and game launching are still in development. No playable release is available here yet.

CurseForge integration is optional and requires approved API access. Third-party distribution choices remain with mod authors.

What works today?

Local profiles, Modrinth browsing and supported mod installs, mod enable/disable controls, favorite-server status checks, Java discovery, launch settings and readiness checks.

Is Astrix an official Minecraft product?

No. Astrix is an independent project and is not approved by or associated with Mojang or Microsoft.
